# Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `/` | Focus search bar |
| `Up` / `Down` | Navigate session list |
| `Enter` | Select highlighted session |
| `Escape` | Close panel, lightbox, or clear search |
| `Cmd+R` / `Ctrl+R` | Refresh session list |
| Double-click | Expand session to full-panel view |
| Right-click | Open context menu |

## Context Menu Actions

Right-click a session to access:

| Action | Description |
|--------|-------------|
| Strip all images | Remove all image data from the session |
| Resize all images | Shrink all images to a target size |
| Copy resume command | Copy the Claude Code `/resume` command for this session |
| Export as markdown | Download the session as a `.md` file |
| Scan for secrets | Check for leaked credentials |

## Help Panel

Press `?` or click the help button in the toolbar to open the help panel, which displays all available keyboard shortcuts.
