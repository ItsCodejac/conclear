# Chat Tab

The Chat tab provides a conversation replay view for the selected session. It displays user and assistant messages with clean formatting.

## Message Display

Messages are rendered with:

- **Role indicator** -- user or assistant, visually distinguished.
- **Timestamp** -- when the message was sent.
- **Text content** -- the message body. Tool use results and internal protocol messages are filtered out for readability.
- **Image indicator** -- if the message includes an image, it is noted (and can be viewed in the Images tab).

## Full Panel Mode

Double-click the session or use the expand control to open the chat in full-panel mode, giving the conversation the full width of the window.

## Search

Search within the conversation to find specific messages. Matches are highlighted.

## Filtering

Filter messages by role (user only, assistant only, or both) to focus on specific parts of the conversation.

## Export

Export the conversation as a markdown document from the context menu or the toolbar. The export includes all user and assistant messages with timestamps and clean formatting.
