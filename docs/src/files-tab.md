# Files Tab

The Files tab shows all files that were read, edited, or written during a session, with full version history.

## File List

Each file entry shows:

- **File path** -- the full path of the file.
- **Version count** -- how many times the file was touched during the session.
- **Operations** -- which operations were performed (read, edit, write).
- **Last modified** -- timestamp of the most recent version.

## Version History

Click a file to see all its versions. Each version shows:

- **Operation type** -- read, edit, or write.
- **Timestamp** -- when this version was captured.
- **Line count** and **size** -- dimensions of the file content.
- **Content preview** -- first 200 characters.

## Code Viewer

Click a version to open it in the code viewer with:

- **Syntax highlighting** -- powered by highlight.js, supporting all major languages.
- **Line numbers** -- for easy reference.
- **Copy button** -- copy the full file content to clipboard.

## File Recovery

The Files tab is useful for recovering lost code. If a file was edited or overwritten, you can browse to any previous version and copy its content. See the [File Recovery](file-recovery.md) section for details.
